## Hi there 👋

*欢迎来到 Team Quaver 的组织！*

Team Quaver，是 Quaver Music 开发组所属组织，它是一个跨平台（目前仅限 Linux，未来版本会适配 Windows / macOS）的，基于 Electron + Vite + Python（未来是 Go）实现的 QQ 音乐第三方客户端。其目的是为了解决 Linux 版本 QQ 音乐难用的问题。
